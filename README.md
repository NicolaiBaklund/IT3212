# IT3212
Group project for the course Datadriven software @ NTNU

## Assignement 1
This project is a two-part data processing pipeline. It first prepares electricity and weather data for analysis, followed by feature engineering and dimensionality reduction on image-based data.

## Assignement 2
This module focuses on transforming raw image data into meaningful information using frequency analysis, dimensionality reduction, and descriptor extraction.

## Assignement 3
This module implements a full machine learning pipline from raw image preprocessing to modern deep learning to solve emotion recognition problem. 

## Assignement 4
This project builts on assignement 3 and use powerful supervised models for classification and unsupervised clustering algorithms to inspect the natural groupings in the dataset.
